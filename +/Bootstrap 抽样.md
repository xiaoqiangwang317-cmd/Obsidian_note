在**随机森林（Random Forest）**里面，**Bootstrap** 是整个算法最核心的思想之一，它解决的是**如何让每棵树看到不同的数据**，从而增加树之间的差异性（Diversity）。

---

## 一句话理解

> **Bootstrap = 有放回随机抽样（Sampling with Replacement）**

也就是说：

从原始训练集里面随机抽样，但是**抽完以后放回，再继续抽**。

---

## 举个例子

假设原始数据集有

|编号|数据|
|---|---|
|1|A|
|2|B|
|3|C|
|4|D|
|5|E|

一共有 **5 个样本**。

Bootstrap 会随机抽 **5 次**（一般抽样数量和原数据一样）。

例如：

第一次抽：

```
B
```

放回。

第二次抽：

```
D
```

放回。

第三次：

```
B
```

第四次：

```
A
```

第五次：

```
E
```

最后得到新的训练集：

```
B
D
B
A
E
```

注意：

- B 出现了两次
    
- C 根本没出现
    

这就是 Bootstrap。

---

## 为什么叫"有放回"？

因为每抽一次，都把数据放回去。

所以：

下一次还有可能抽到同一个样本。

因此：

```
一个样本
↓

可能出现很多次
```

也可能

```
一次都没有出现
```

---

## Bootstrap 在随机森林里的作用

假设：

原始数据：

```
10000 条
```

随机森林有

```
100 棵树
```

那么：

不是所有树都用同一份数据。

而是：

```
Tree1
← Bootstrap①

Tree2
← Bootstrap②

Tree3
← Bootstrap③

...

Tree100
← Bootstrap100
```

也就是说：

每棵树都有属于自己的训练集。

例如：

```
Tree1

A B C D E F G ...

```

Tree2

```
A C C D H H I ...
```

Tree3

```
B B E F G K M ...
```

可以看到：

每棵树的数据都不一样。

---

## 为什么要这样？

如果所有树：

```
都训练同一份数据
```

那么：

得到的树就会很像。

例如：

```
Tree1

如果年龄>30
↓

收入>5000
↓

买车
```

Tree2

```
年龄>30
↓

收入>5200
↓

买车
```

几乎一样。

那么：

100 棵树投票

其实没有意义。

---

Bootstrap 后：

每棵树看到的数据不同。

例如：

```
Tree1

年龄
↓

收入
↓

买车
```

Tree2

```
职业
↓

学历
↓

买车
```

Tree3

```
城市
↓

年龄
↓

买车
```

树之间开始有差异。

随机森林最后：

```
100 棵树投票
```

误差会互相抵消。

这就是随机森林比单棵决策树稳定很多的原因。

---

## 有没有数据永远没被抽到？

有。

这是 Bootstrap 一个非常重要的性质。

假设：

训练集有

```
N 个样本
```

Bootstrap 也是抽

```
N 次
```

那么：

一个样本一次都没被抽到的概率近似为

                $\left(1-\frac1N\right)^N$

当 (N) 很大时，

                $\left(1-\frac1N\right)^N  \approx e^{-1}  \approx 0.368$
也就是说：

> **大约 36.8% 的样本不会进入某一棵树的训练集。**

这些没有被抽到的数据叫做：

**袋外样本（Out-of-Bag，OOB）**。

---

## OOB 有什么用？

由于这些样本没有参与对应那棵树的训练，因此可以拿来测试那棵树，相当于天然的验证集。

例如：

```
10000 个样本

↓

Bootstrap

↓

6300 个左右不同样本
（其中一些会重复出现）

+

3700 个左右没有出现
(OOB)
```

训练：

```
6300
↓

训练树
```

测试：

```
3700

↓

预测

↓

计算准确率
```

最后：

所有树的 OOB 结果综合起来，

就得到 **OOB Error（袋外误差）**。

它可以近似反映模型的泛化能力，因此很多情况下**不需要再单独划分验证集**。

---

## Bootstrap 与随机森林的另一个随机性

很多人以为随机森林只有 Bootstrap，其实它有 **两层随机性**：

1. **Bootstrap（随机样本）**
    
    - 每棵树使用不同的训练样本。
        
2. **随机特征（Random Feature Selection）**
    
    - 每个节点划分时，不是在全部特征中寻找最佳划分，而是随机选取一部分特征，再从中选择最优划分。
        

例如，有 100 个特征：

```
全部特征
↓

随机抽取 10 个

↓

只在这 10 个里面寻找最佳划分
```

这样进一步降低了树之间的相关性。

---

## 总结

随机森林中的 Bootstrap 可以概括为：

- **定义**：有放回随机抽样（Sampling with Replacement）。
    
- **目的**：让每棵决策树看到不同的训练数据，提高树之间的多样性。
    
- **结果**：同一个样本可能重复出现，也可能完全不出现。
    
- **副产品**：约 36.8% 的样本成为袋外样本（OOB），可用于估计模型的泛化误差。
    
- **与随机特征共同作用**：Bootstrap 提供“随机样本”，随机特征提供“随机变量”，二者共同构成了随机森林中“随机”的来源，使得最终通过多棵树投票能够有效降低方差、提升模型的稳定性和泛化能力。

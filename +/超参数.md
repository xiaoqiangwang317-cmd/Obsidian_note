实际上，**超参数（Hyperparameter）并不是从 XGBoost 才出现的，而是所有机器学习模型都有。** 只是 XGBoost 的超参数特别多、影响特别大，所以论文和教程都会重点介绍。

---

# 一、什么是超参数？

先区分两个容易混淆的概念。

## ① 参数（Parameter）

参数是：

> **模型在训练过程中自动学习出来的。**

例如线性回归：
                     $y=w_1x_1+w_2x_2+b$

这里：

- (w_1)
    
- (w_2)
    
- (b)
    

都是参数。

训练开始：

```text
w1 = ?
w2 = ?
b  = ?
```

模型不断优化：

```text
↓

w1 = 2.35
w2 = -0.81
b = 0.57
```

这些都是模型自己算出来的。

---

## ② 超参数（Hyperparameter）

超参数是：

> **训练开始之前，人提前设定好的参数。**

例如：

```text
学习率 = 0.1

树的数量 = 100

树最大深度 = 6

L2正则 = 1

L1正则 = 0
```

这些：

模型不会自己学习。

都是：

> **你告诉模型的。**

---

# 二、为什么叫"超（Hyper）"参数？

因为它：

**控制参数如何学习。**

举个例子：

炒菜。

参数：

```text
盐放多少
```

最后炒出来决定。

而超参数：

```text
火开多大？

炒多久？

锅有多深？
```

这些都是厨师提前决定。

所以：

超参数

↓

决定训练过程。

参数

↓

训练得到结果。

---

# 三、举个最简单的例子

假设训练一棵决策树。

你可以规定：

```text
最大深度 = 3
```

那么：

```
        根
      /    \
    ○       ○
   / \     / \
```

最多：

三层。

如果：

```text
最大深度 = 20
```

就会长成：

```
        根
      /
     ○
    /
   ○
  /
 ○
```

树特别复杂。

所以：

**最大深度**就是：

超参数。

# 四、为什么以前讲 SVM、随机森林的时候没提？

其实都有。

例如：

## SVM

超参数：

- C（正则化强度）
    
- kernel（核函数）
    
- gamma
    

例如：

```text
SVM(
C=1,
kernel='rbf',
gamma=0.1
)
```

这里：

全部都是超参数。

---

## 随机森林

超参数：

```text
树数量

n_estimators
```

例如：

```text
100棵树
```

还有：

```text
最大深度

max_depth
```

还有：

```text
min_samples_leaf
```

都是超参数。

---

## KNN

超参数只有一个最经典：

```text
K = 5
```

为什么取：

5

不是：

3

不是：

20

这是人决定的。

---

## 逻辑回归

也有：

```text
L2

λ
```

正则化强度。

也是超参数。

# 五、为什么到了 XGBoost 才开始疯狂讲超参数？

因为：

XGBoost：

**超参数太多了。**

例如：

```text
max_depth

learning_rate

n_estimators

gamma

subsample

colsample_bytree

lambda

alpha

min_child_weight

max_delta_step

tree_method

grow_policy
```

二三十个都很正常。

为什么？

因为：

XGBoost不仅仅是一种算法。

它其实更像：

> **一个可以高度定制的梯度提升框架。**

里面：

什么都可以调。

---

# 六、举个例子你就懂了

假设：

训练100棵树。

这里：

```text
n_estimators =100
```

这是：

超参数。

训练后：

第一棵树：

```text
叶子：

1.25

-0.73

0.42
```

这些：

叶子权重。

就是：

参数。

所以：

```
开始训练

↓

超参数（你设置）

↓

开始建树

↓

模型学习

↓

得到参数（模型学出来）
```

---

# 七、为什么论文里老说"调超参数"？

因为：

真正影响效果的是：

超参数。

例如：

```text
max_depth=3
```

准确率：

90%

改成：

```text
max_depth=20
```

可能：

训练集：

99%

测试集：

82%

过拟合了。

所以：

研究人员会：

```text
不断尝试

↓

找到最好的一组超参数
```

这叫：

> **超参数调优（Hyperparameter Tuning）**。

# 八、总结（建议记到 Obsidian）

|对比项|参数（Parameter）|超参数（Hyperparameter）|
|---|---|---|
|谁决定？|模型训练得到|人提前设定|
|是否参与学习？|是|否|
|是否会变化？|会|训练过程中通常固定（也有自动调优方法）|
|举例|线性回归权重、神经网络权重、XGBoost 叶子节点权重|学习率、树深、树数量、正则化系数、KNN 的 K 值|

---

### 最后回答你的疑问

你觉得“为什么前面的传统机器学习没怎么提超参数”，其实是**学习顺序导致的**，而不是因为那些模型没有超参数。

如果把传统机器学习按照**工程实现**来学习，你会发现几乎每个模型都有自己的超参数：

- **KNN**：K 值。
    
- **决策树**：最大深度、最小叶子节点样本数等。
    
- **随机森林**：树数量、树深、每次分裂考虑的特征数等。
    
- **SVM**：C、核函数、gamma。
    
- **GBDT**：学习率、树数量、树深。
    
- **XGBoost**：在 GBDT 的基础上又增加了正则化、采样策略、树生长策略等更多超参数，因此调参的重要性更突出。
    

所以，你可以把 **XGBoost** 看作是传统 GBDT 的**工程增强版**：它不仅在算法上引入了目标函数、L1/L2 正则、二阶泰勒展开等创新，还提供了大量超参数，让模型能够针对不同数据集进行精细控制，这也是它长期成为机器学习竞赛和工业界主力算法的重要原因。

### 一、背景：数据并行的显存墙问题

在大模型训练中，即使使用数据并行（每张卡复制完整模型），每张卡仍需存储：

|组件|存储内容|参数量占比|
|---|---|---|
|模型参数 (Parameters)|模型权重|1 × P|
|梯度 (Gradients)|反向传播计算|1 × P|
|优化器状态 (Optimizer States)|如 Adam 的 momentum 和 variance|2 × P（Adam）|

> 对于 Adam 优化器：每 1 个参数需要存 2 个状态量（一阶矩 m、二阶矩 v）  
> 总显存 ≈ (参数 + 梯度 + 优化器状态) = P + P + 2P = **4P 字节**（FP32）

举例：

- 175B 参数的 GPT-3，仅训练就需要 **175B × 4 × 4 bytes = 2.8TB 显存**
    
- 单卡 A100 80GB，需要 35 张卡才能装下参数 + 梯度 + 优化器状态
    

**ZeRO 的目标**：在不增加计算量的前提下，用分布式方式把这些状态切分到多卡，降低单卡显存占用。

---

### 二、ZeRO 的核心思想：分片（Partition）而非复制

传统数据并行：每张卡都存一份完整的参数、梯度、优化器状态。

ZeRO：把这些状态**切成 N 份**，每张卡只存 1/N。

---

### 三、ZeRO 的三个阶段

| 阶段         | 分片内容            | 显存占用（单卡，N卡）        | 通信量          |
| ---------- | --------------- | ------------------ | ------------ |
| **ZeRO-1** | [[Adam\|优化器]]状态 | ≈ 2P/N + 2P        | 与数据并行相同      |
| **ZeRO-2** | 优化器状态 + 梯度      | ≈ 2P/N + P/N + P   | 增加一次梯度通信     |
| **ZeRO-3** | 优化器状态 + 梯度 + 参数 | ≈ 2P/N + P/N + P/N | 大幅增加（每层都要通信） |

> 注：P 是总参数量，假设混合精度训练（FP16 参数/梯度 + FP32 优化器状态）

#### 详细解释：

**ZeRO-1（最轻量）**

- 每张卡：存完整参数（P）、完整梯度（P）、1/N 优化器状态
    
- 节省：优化器状态从 2P → 2P/N
    
- 通信：与数据并行完全相同
    

**ZeRO-2（本题答案）**

- 每张卡：存完整参数（P）、1/N 梯度、1/N 优化器状态
    
- 节省：梯度从 P → P/N
    
- 额外通信：需要在 backward 后做一次 all-reduce 收集梯度（但可以做 overlap）
    

**ZeRO-3（最强）**

- 每张卡：存 1/N 参数、1/N 梯度、1/N 优化器状态
    
- 节省：参数从 P → P/N
    
- 额外通信：forward/backward 时动态收集参数（每层都要）

### 四、ZeRO 的通信优化

ZeRO 不是简单切分，而是配合计算流做优化：

|阶段|Forward|Backward|
|---|---|---|
|ZeRO-1|正常|正常|
|ZeRO-2|正常|梯度分片后 all-reduce|
|ZeRO-3|动态 gather 参数|动态 gather 参数 + 分片梯度|

**ZeRO-3 的通信模式**（重要）：

- 不是全部参数一次性广播，而是**按层处理**
    
- 计算第 1 层前向 → 广播第 1 层参数 → 计算完成 → 丢弃
    
- 这样峰值显存 ≈ 单层参数大小，而不是全部参数

### 五、ZeRO 的实际应用

|框架|ZeRO 实现|
|---|---|
|DeepSpeed（微软）|原生 ZeRO，ZeRO-3 + Offload 到 CPU/NVMe|
|PyTorch FSDP|等价于 ZeRO-3|
|Megatron-LM|与 ZeRO 互补（张量并行 + 流水线并行）|

**ZeRO-Offload**：把优化器状态和梯度 offload 到 CPU 内存或 NVMe  
**ZeRO-Infinity**：offload 到 NVMe，支持超大模型（如 1T 参数）

### 六、ZeRO 与并行的关系

text

数据并行 (DP)     ← ZeRO-1/2/3 的底层通信模式
张量并行 (TP)     ← Megatron 做的是 TP，与 ZeRO 正交
流水线并行 (PP)   ← GPT-3 用的方式

ZeRO 常与 TP、PP 混合使用（3D 并行）：

- TP：单机内切参数（减少通信）
    
- PP：多机间按层切（减少跨机通信）
    
- ZeRO：切分优化器状态（省显存）

## 总结表

|ZeRO 阶段|分片内容|显存节省|额外通信|适用场景|
|---|---|---|---|---|
|ZeRO-1|优化器状态|2P → 2P/N|无|小集群，想简单省显存|
|ZeRO-2|优化器 + 梯度|3P → (2P + P)/N + P|少量|最常见选择，本题答案|
|ZeRO-3|优化器 + 梯度 + 参数|4P → 4P/N|较多|超大模型，单卡放不下一层|

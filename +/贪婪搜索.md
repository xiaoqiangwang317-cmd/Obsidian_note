## 二、详细对比表（核心考点）

|策略|操作|随机性|候选数|适用场景|典型问题|
|---|---|---|---|---|---|
|**贪婪搜索**|每步取 argmax|❌|1|代码生成、数学、翻译|重复、局部最优|
|**束搜索**|维护 k 条路径，取总分最高|❌|k|翻译、摘要|计算量大、仍可能重复|
|**温度采样**|除以 T 后 softmax|✅|V（全部）|控制多样性程度|T 高可能胡言乱语|
|**Top‑k 采样**|限制在 k 个最高中随机|✅|k|对话、中等多样性|k 固定不够灵活|
|**Top‑p 采样**|限制在累积概率达 p 的集合中随机|✅|可变|创意写作、高多样性|实现稍复杂|
|**混合 (k+p)**|先 Top‑k，再 Top‑p|✅|可变|GPT‑4/Claude 默认|参数需调优|

## 三、具体例子演示

**原始概率分布**（某一步）：

text

token:    A     B     C     D     E     F     G     H     I     J
prob:   0.4   0.2   0.12  0.1   0.08  0.04  0.02  0.02  0.01  0.01

### 1. 贪婪搜索

**输出**：A  
**原因**：0.4 最高，直接选

### 2. 束搜索（k=2）

text

第1步：候选 A(0.4), B(0.2)
第2步：扩展 A 和 B 的所有可能，选总分最高的 2 条路径
最终：选路径总分最高的完整序列

**特点**：不逐词独立选，而是考虑序列整体分数

### 3. 温度采样（T=1.2，平滑）

text

公式：p_t = exp(log(p)/T) / sum(exp(log(p)/T))
T>1：概率分布变平缓，低概率 token 被选中概率 ↑
T<1：概率分布变尖锐，高概率 token 概率 ↑
T=1：原始分布不变

**示例效果**：A 从 0.4 → 约 0.35，D 从 0.1 → 约 0.13（低概率上升）

### 4. Top‑k 采样（k=3）

text

候选集：A(0.4), B(0.2), C(0.12)
重新归一化（和=0.72）：
A: 0.4/0.72=0.556
B: 0.2/0.72=0.278
C: 0.12/0.72=0.167
随机采样 → 可能抽到 B 或 C，但 A 概率最高

### 5. Top‑p 采样（p=0.6）

text

累积概率：
A(0.4) → 0.4
+ B(0.2) → 0.6  ✓ 达到阈值
候选集：A, B
重新归一化（和=0.6）：
A: 0.4/0.6=0.667
B: 0.2/0.6=0.333
随机采样 → 2/3 概率选 A，1/3 概率选 B

### 6. 混合策略（k=50, p=0.9）

text

先取概率最高的 50 个 token
再从这 50 个中做 Top‑p=0.9（累积概率到 90%）
综合了 Top‑k（避免尾部垃圾）和 Top‑p（动态调整集合）

## 四、算法伪代码（直观理解）

python

# 贪婪搜索
def greedy(probs):
    return argmax(probs)
# 束搜索（简化）
def beam_search(model, prompt, k=2):
    candidates = [(prompt, 1.0)]
    for _ in range(max_len):
        new_candidates = []
        for seq, score in candidates:
            probs = model.get_next_probs(seq)
            for token, prob in top_k(probs, k):
                new_candidates.append((seq+token, score*prob))
        candidates = top_k_by_score(new_candidates, k)
    return best(candidates)
# 温度采样
def temperature_sampling(probs, T=1.0):
    logits = log(probs)
    scaled_logits = logits / T
    new_probs = softmax(scaled_logits)
    return random_choice(new_probs)
# Top‑k 采样
def top_k_sampling(probs, k=50):
    top_k_tokens = indices_of_top_k(probs, k)
    new_probs = renormalize(probs[top_k_tokens])
    return random_choice(new_probs)
# Top‑p 采样
def top_p_sampling(probs, p=0.95):
    sorted_indices = argsort(probs, descending=True)
    cumulative = 0
    selected = []
    for idx in sorted_indices:
        selected.append(idx)
        cumulative += probs[idx]
        if cumulative >= p:
            break
    new_probs = renormalize(probs[selected])
    return random_choice(new_probs)

## 五、你应该记住的判断逻辑

当你看到一道题问解码策略时：

1. **是否考虑整体序列分数？**
    
    - 是 → 束搜索
        
    - 否 → 其他策略
        
2. **是否每步只选最高？**
    
    - 是 → 贪婪搜索
        
    - 否 → 看是否有随机性
        
3. **是否有随机性？**
    
    - 否 → 贪婪/束搜索
        
    - 是 → 温度/Top‑k/Top‑p
        
4. **随机性来源是什么？**
    
    - 改变分布形状 → 温度采样
        
    - 限制候选数 → Top‑k
        
    - 限制累积概率 → Top‑p
        
    - 两者都限制 → 混合策略
        
5. **算力要求？**
    
    - 最小 → 贪婪（O(1)）
        
    - 小 → 温度/Top‑k/Top‑p（O(V) 或 O(V log V)）
        
    - 大 → 束搜索（O(k × V)）

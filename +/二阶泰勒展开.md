这个问题问得非常好，也是 **XGBoost 相对于传统 GBDT 最大的创新之一**。

其实，**二阶泰勒展开并不难**。你只要理解它是在做什么，而不是去死记数学公式。

---

# 先说结论

XGBoost 的目标是：

> **找到一个容易计算的函数，来近似真正复杂的损失函数。**

它采用的方法就是：

> **用泰勒展开把复杂函数近似成一个二次函数。**

为什么是二次函数？

因为：

- 一次函数很好优化；
    
- 二次函数更接近真实曲线；
    
- 二次函数还能直接求最优解。
    

---

# 一、什么是泰勒展开？

假设有一个很复杂的函数

例如

```
y = ln(x)
```

或者

```
y = e^x
```

它们都不是直线。

例如：

```
        ●
      ●
    ●
  ●
●
```

如果我们只关心某一个点附近，比如

```
x = 1
```

那么其实没必要知道整个曲线。

只需要知道：

> **这一小段长什么样。**

于是数学家想到：

> 能不能用简单函数去代替它？

答案就是：

```
常数
+
一次项
+
二次项
+
三次项
+
……
```

这个过程就叫：

> **泰勒展开（Taylor Expansion）**

---

## 二、不同阶数代表什么意思？

### 0阶

只看当前位置

```
f(x)

↓

≈ 常数
```

就是一个点。

---

### 一阶展开

就是再加上斜率。

```
f(x)

≈

常数
+
斜率
```

也就是：

**切线。**

图像：

```
真实函数

      )
    )
  )
)

---------

切线
```

所以：

一阶展开就是：

> **用切线近似曲线。**

---

### 二阶展开

切线有个问题：

如果曲率很大，

切线很快就偏离真实曲线。

于是：

再加入：

> **弯曲程度。**

于是得到：

```
常数
+
一次项
+
二次项
```

图像变成：

```
真实函数

      )
    )
  )
)

近似

    )
   )
  )
```

它已经开始有：

**弯曲。**

所以：

二阶展开比切线更准确。

---

## 三、为什么叫二阶？

因为：

二阶对应：

**二阶导数。**

我们知道：

一阶导数

```
f'(x)
```

表示：

> 斜率。

二阶导数

```
f''(x)
```

表示：

> **斜率变化得快不快。**

举例：

汽车。

速度：

```
80km/h
```

速度变化率：

```
加速度
```

这里：

```
位置
↓

速度（一阶导）

↓

加速度（二阶导）
```

所以：

二阶导数描述的是：

> **函数弯得厉不厉害。**

可以这样理解：

第一项：

```
当前位置
```

第二项：

```
斜率
```

第三项：

```

```

# 五、放到 XGBoost 里面

现在来看损失函数：

```
Loss(w)
```

它其实也是一个很复杂的函数。

例如：

```
Loss

│
│      ●
│    ●
│  ●
│●
└────────
        w
```

XGBoost 不直接优化它。

而是在当前参数附近：

用二阶泰勒展开：

[  
Loss  
\approx  
Loss_{old}  
+  
g\Delta  
+  
\frac12h\Delta^2  
]

这里：

- (g) = 一阶导数（Gradient，梯度）
    
- (h) = 二阶导数（Hessian，海森矩阵，对于单变量就是二阶导数）
    

于是：

复杂函数

↓

变成

```
二次函数
```

例如：

```
ax²+bx+c
```

二次函数最大的优点就是：

> **可以直接算出最优点，而不用盲目试。**

---

# 六、为什么传统 GBDT 只有一阶？

传统 GBDT：

```
Loss

↓

梯度

↓

拟合残差
```

也就是：

只知道：

> **应该往哪个方向走。**

但不知道：

> **这条路弯不弯。**

就像开车：

```
只知道方向

不知道急转弯
```

所以：

步子可能迈大了。

也可能迈小了。

---

# 七、XGBoost为什么更好？

因为：

它不仅知道：

```
往哪里走
```

还知道：

```
这里是不是一个谷底？
```

例如：

```
Loss

        ●
      ●
    ●
  ●
●
```

梯度告诉你：

```
↓

往左
```

但是：

如果这里很陡：

```
\
 \
  \
```

应该：

```
小步走
```

如果这里很平：

```
____
```

应该：

```
大步走
```

这个信息是谁提供的？

就是：

> **二阶导数（Hessian）。**

因此，XGBoost 能根据损失函数的弯曲程度动态调整优化，更容易快速、稳定地接近最优解。

---

# 八、你可以这样理解 XGBoost 的整个优化过程

```
目标函数
        │
        ▼
Loss + 正则化
        │
        ▼
二阶泰勒展开
        │
        ▼
得到一个容易优化的二次函数
        │
        ▼
根据 Gradient（一阶导）
知道往哪里走
        │
        ▼
根据 Hessian（二阶导）
知道走多快、是否接近谷底
        │
        ▼
直接求出这一轮树叶节点的最优权重
```

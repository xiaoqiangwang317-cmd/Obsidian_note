在论文的实验部分，**MAE** 的全称是 **Mean Absolute Error（平均绝对误差）**。

它是机器学习、深度学习以及统计学中，用来评估**回归模型**（即预测连续数值的模型，如预测房价、温度、销售额等）性能的一个非常常见的指标。

以下是对 MAE 的详细拆解，帮助你更好地理解论文中的内容：

### 1. 通俗解释
简单来说，MAE 就是**模型预测值与真实值之间“差值”的平均数**。
* 如果 MAE = 5，意味着你的模型在预测时，平均每次会偏离真实值 5 个单位。
* **MAE 越小，说明模型的预测越准确。**（理想状态下 MAE = 0，表示预测完全正确）。

### 2. 计算公式
$$MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

* $n$：样本的总数量。
* $y_i$：第 $i$ 个样本的**真实值**（Ground Truth）。
* $\hat{y}_i$：第 $i$ 个样本的**预测值**（Prediction）。
* $|\ |$：绝对值符号（保证无论预测偏高还是偏低，误差都是正数）。

**举个简单的例子：**
假设你要预测三天的气温，真实气温是 [10℃, 20℃, 30℃]，你的模型预测的是 [12℃, 19℃, 25℃]。
* 第一天误差：|10 - 12| = 2
* 第二天误差：|20 - 19| = 1
* 第三天误差：|30 - 25| = 5
* **MAE** = (2 + 1 + 5) / 3 = **2.67℃**
（结论：你的模型平均预测偏差约为 2.67 度）。

### 3. MAE 的特点与优缺点
在论文中，作者选择报告 MAE 通常是因为它有以下特点：

* **优点 1：直观易懂，单位一致。** MAE 的单位和原始数据的单位是一样的（比如预测房价，MAE 的单位就是“万元”），非常方便向读者解释模型的实际误差有多大。
* **优点 2：对异常值（Outliers）具有鲁棒性（不敏感）。** 因为 MAE 使用的是绝对值，误差是线性增长的。如果有一个极其离谱的错误预测，它不会像 MSE（均方误差）那样把整体指标拉得极其夸张。

* **缺点：** 由于绝对值函数在 0 点处不可导，所以在模型训练阶段（求导反向传播时）通常不直接用 MAE 作为损失函数去优化，而是更多用在**测试阶段作为评估指标**向读者展示效果。

### 4. 论文中看 MAE 时需要注意的 2 点
1. **必须结合数据量级看：** MAE 是一个绝对数值，孤立的数字没有意义。比如预测成年人身高 MAE=2（很大），但预测城市人口 MAE=2（极其精准）。一定要看它占真实值平均水平的比例。
2. **常与 MSE / RMSE 结合出现：** 
   * 如果论文中 **MAE 很小，但 RMSE 很大**，说明模型整体预测不错，但**出现了几次非常离谱的预测（异常值）**。
   * 如果 **MAE 和 RMSE 差不多大**，说明模型的误差分布比较均匀，没有特别离谱的预测。

**总结：** 当你在论文实验结果表格里看到 MAE 时，把它理解为**“模型平均每次猜错了多少”**即可，数字越小代表模型越好。

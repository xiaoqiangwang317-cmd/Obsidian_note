# 一、Why：为什么要引入激活函数？

先看最原始的神经网络。

假设只有线性变换：

```
x 
↓
W1x+b1 
↓
W2x+b2 
↓
W3x+b3 
↓
输出
```

看起来有很多层。

实际上：

```
(W3(W2(W1x+b1)+b2)+b3)
```

最终仍然可以化简成：

```
Wx+b
```

也就是说：

> 多层线性层 = 一层线性层

无论堆多少层：

```
线性+线性+线性=线性
```

模型无法学习复杂规律。

例如：

```
图片
↓
猫？狗？汽车？
```

这种非线性关系根本学不出来。

---

因此需要：

```
Linear
↓
Non-Linear
↓
Linear
↓
Non-Linear
```

让网络拥有：

```
非线性表达能力
```

这就是激活函数诞生的原因。

---

一句话：

> 激活函数的作用是为神经网络引入非线性能力，使模型能够拟合复杂函数。

---

# 二、What：什么是激活函数？

本质：

```
输入 x
↓
经过一个函数 f(x)
↓
输出
```

即：

```
y=f(x)
```

例如：

```
f(x)=Sigmoid(x)
```

或者：

```
f(x)=ReLU(x)
```

---

放在神经元里：

```
输入 
↓
wx+b 
↓
Activation 
↓
输出
```

数学形式：

```
y=f(wx+b)
```

其中：

```
f
```

就是激活函数。

---

# 三、How：怎么使用激活函数？

在神经网络中：

```
Linear
↓
Activation
↓
Linear
↓
Activation
```

不断交替出现。

例如 Transformer：

```
Attention
↓
FFN   
↓
Linear
↓
GELU
↓
Linear
```

激活函数一般放在：

```
线性层之后
```

用于增加非线性表达能力。

这部分特别适合面试。


---

## 第一代：[[Sigmoid]]（1980s-2000s）

代表：

σ(x)=11+e−x\sigma(x)=\frac{1}{1+e^{-x}}
σ(x)=1+e−x1​

特点：

```
输出范围：(0,1)
```

优点：

- 平滑
- 可导
- 可解释为概率

广泛用于：

- 二分类
- 早期神经网络

---

缺点：

### 梯度消失

导数：

```
最大只有0.25
```

层数一深：

```
梯度≈0
```

训练困难。

---

## 第二代：Tanh

公式本质上是 Sigmoid 改进版。

输出：

```
(-1,1)
```

优点：

```
均值接近0
```

训练更稳定。

---

但问题仍然存在：

```
梯度消失
```

没彻底解决。

---

## 第三代：ReLU（2010年前后爆发）

代表公式：

f(x)=max⁡(0,x)
f(x)=\max(0,x)
f(x)=max(0,x)

革命性意义：

```
x>0  导数=1
```

梯度可以顺畅传播。

---

优点：

### 训练快

### 计算简单

### 缓解梯度消失

因此推动了：

- AlexNet
- 深度学习爆发

---

这是深度学习真正崛起的**重要原因**之一。

---

缺点：

### Dying ReLU

例如：

```
x<0
```

永远输出：

```
0
```

神经元可能永久失活。

---

## 第四代：Leaky ReLU

改进：

```
x<0
```

不直接变0。

而是：

```
0.01x
```

保留一点梯度。

解决：

```
Dying ReLU
```

问题。

---

## 第五代：[[GELU]]

Transformer时代的重要激活函数。

代表：

- BERT
- GPT-2
- GPT-3

---

思想：

ReLU：

```
保留或直接砍掉
```

太粗暴。

---

GELU：

```
按照概率保留信息
```

更加平滑。

---

效果：

```
Transformer + GELU
```

通常优于：

```
Transformer + ReLU
```

因此成为经典搭配。

---

## 第六代：GLU家族

随着模型越来越大：

研究者发现：

```
不仅需要激活还需要门控
```

即：

```
哪些信息保留
哪些信息丢弃
```

---

出现：

```
GLU GEGLU ReGLU SwiGLU
```

---

本质：

```
激活函数 + 门控机制
```

---

## 第七代：SwiGLU（当前主流）

目前大量 LLM 使用。

例如：

- Meta 的 Llama系列
- Google 的 PaLM系列
- 许多开源大模型

---

核心思想：

```
Swish + GLU
```

兼顾：

```
表达能力 + 训练稳定性 + 参数效率
```

---

因此成为：

```
2024~2026 主流LLM激活函数
```

## 一、一句话定位

> **Adam = RMSprop + Momentum**  
> = 自适应学习率 + 带动量的梯度下降

---

## 二、为什么需要 Adam？（背景）

### SGD 的问题

|问题|描述|
|---|---|
|学习率难调|一个学习率对所有参数一样，不合适|
|收敛慢|平坦区域步长太小，陡峭区域步长太大|
|易卡在鞍点|梯度接近 0 时，SGD 走不动|

### Momentum：解决“卡在鞍点/震荡”

- 积累历史梯度方向
    
- 在一致方向上加速
    

### RMSprop：解决“不同参数需要不同学习率”

- 每个参数有自己的自适应学习率
    
- 梯度大的参数学习率小，梯度小的参数学习率大
    

**Adam = 两者结合**

## 三、Adam 核心公式

### 符号定义

|符号|含义|
|---|---|
|gtgt​|当前梯度（小批量梯度）|
|mtmt​|一阶矩估计（Momentum，均值/方向）|
|vtvt​|二阶矩估计（RMSprop，方差/缩放）|
|β1,β2β1​,β2​|衰减率（通常 0.9, 0.999）|
|ηη|学习率（通常 1e-3）|
|ϵϵ|数值稳定小量（通常 1e-8）|

### 更新步骤

text

1. 计算梯度：g_t = ∇L(θ_{t-1})
2. 更新一阶矩（动量）：m_t = β₁·m_{t-1} + (1-β₁)·g_t
3. 更新二阶矩（自适应学习率）：v_t = β₂·v_{t-1} + (1-β₂)·g_t²
4. 偏差修正（因为初始 m₀, v₀ = 0）：m̂_t = m_t / (1-β₁ᵗ),  v̂_t = v_t / (1-β₂ᵗ)
5. 参数更新：θ_t = θ_{t-1} - η · m̂_t / (√v̂_t + ε)

## 四、直观理解（不用背公式）

|组件|作用|类比|
|---|---|---|
|**m_t**|记录梯度的**方向惯性**|小球滚动，有速度|
|**v_t**|记录梯度的**大小波动**|路况反馈：颠簸路段慢点走|
|**m̂_t / √v̂_t**|方向 ÷ 历史幅度|归一化的更新步长|
|**偏差修正**|解决起步阶段方向不准|热身阶段|

### 关键效果

- **梯度频繁变号（震荡）** → v_t 大 → 步长小 → 不会发散
    
- **梯度方向一致** → m_t 大，v_t 小 → 步长大 → 加速收敛
    
- **每个参数独立学习率** → 适合稀疏特征（如 Embedding）

## 五、超参数详解

|超参数|默认值|作用|调参建议|
|---|---|---|---|
|ηη（学习率）|1e-3|整体步长|最常调，1e-4~1e-2 常见|
|β1β1​|0.9|动量衰减率|很少调|
|β2β2​|0.999|二阶矩衰减率|很少调|
|ϵϵ|1e-8|防止除零|几乎不动|

## 六、与其他优化器对比

|优化器|自适应学习率|动量|适用场景|
|---|---|---|---|
|SGD|❌|❌|简单问题，需要精细调参|
|SGD + Momentum|❌|✅|比 SGD 快，收敛平稳|
|RMSprop|✅|❌|RNN、在线学习|
|**Adam**|✅|✅|**最通用，大多数场景首选**|
|AdamW|✅|✅|Adam + 正确解耦的 L2 正则化|
|Adagrad|✅|❌|稀疏数据（但学习率只降不升）|

## 七、Adam 的优点与缺点

### ✅ 优点

|优点|说明|
|---|---|
|收敛快|结合动量，在平坦/陡峭区域都有效|
|学习率鲁棒|默认 1e-3 在多数任务上可用|
|适合大规模数据|每个参数独立学习率，对稀疏特征友好|
|工程稳定|训练几乎不会发散|

### ⚠️ 缺点

|缺点|说明|改进方案|
|---|---|---|
|泛化可能不如 SGD|有时在测试集上比 SGD 差|后期换 SGD|
|需要存储 m 和 v|参数量 × 2 的显存|AdamW 没解决|
|对某些任务学习率仍敏感|尤其是 Transformer|用 AdamW + warmup|

## 八、AdamW（现在更常用）

### 为什么需要 AdamW？

**原版 Adam 的 L2 正则化实现有问题**：

- L2 正则化应该加在损失上
    
- Adam 的实现把它混入了自适应学习率中 → 正则化效果打折扣
    

**AdamW**（2017，Loshchilov & Hutter）：

- 把权重衰减（weight decay）**独立出来**，不经过自适应学习率
    
- 现在几乎所有大模型训练都用 **AdamW**，不是原版 Adam
    

### AdamW 更新公式（简化）

text

θ_t = θ_{t-1} - η · ( m̂_t / (√v̂_t + ε) + λ·θ_{t-1})
         ↑                    ↑
    Adam 更新              独立的权重衰减

## 九、学习率调度与 Adam 配合

|策略|做法|适用场景|
|---|---|---|
|**Linear Warmup**|前几步学习率从 0 → 1e-3|**大模型必用**，防止 Adam 初期的 m̂/v̂ 不准|
|**Cosine Decay**|学习率余弦下降到 0|预训练常用|
|**Step Decay**|每隔 N 步学习率乘 0.1|小规模任务|
|**No Decay**|固定学习率|很多 Adam 任务也可以|

> **大模型训练标准配方**：AdamW + Warmup + Cosine Decay

## 十、与“第 6 题小批量噪声”的联系

你刚做的第 6 题（SGD 小批量噪声）与 Adam 的关系：

|对比维度|SGD|Adam|
|---|---|---|
|依赖噪声跳出局部最优？|✅ 是|❌ 不需要（自适应+动量已能克服）|
|对小批量噪声的敏感性|高|低（因为 m 和 v 平滑了噪声）|
|收敛终点|可能在最优点附近波动|能更接近最优点|
|批量大小建议|小批量（噪声帮助）|可中大批量|

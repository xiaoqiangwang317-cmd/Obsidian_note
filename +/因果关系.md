## 一、考情分析（★★★★★）

国考类比推理高频关系之一。

一般占：

```
★★★★☆
```

特点：

```
喜欢和功能关系对应关系症状关系工具关系混着考。
```

---

## 二、识别特征

看到这些词首先想到因果。

```
导致造成引起诱发形成产生促进阻碍影响加剧缓解
```

包括隐含因果：

```
病毒感染疾病↓感染导致疾病
```

---

## 三、命题模型

### 模型①

原因→结果

例如：

```
感染↓疾病
```

---

### 模型②

结果→原因（方向陷阱）

例如

```
疾病感染
```

---

### 模型③

多个原因

```
吸烟熬夜↓肺病
```

---

### 模型④

多个结果

```
洪水↓停电↓交通瘫痪
```

---

## 四、高频陷阱

这里就是国考最爱出的。

例如

### 陷阱①

症状

≠

原因

例如

```
发烧疾病
```

很多人会误认为：

发烧导致疾病。

其实

```
疾病↓发烧
```

---

### 陷阱②

工具

≠

原因

例如

```
CT疾病
```

CT不是导致疾病。

---

### 陷阱③

条件

≠

原因

例如

```
空气燃烧
```

空气不是燃烧原因。

只是条件。

---

## 五、经典真题

### 2026 国考

```
颅内疾病：颅内感染岩石断裂：地壳应力
```

总结：

```
感染↓疾病应力↓断裂
```

属于：

**因果关系**

## 六、易混关系

|易混|如何区分|
|---|---|
|症状|不是病因|
|工具|不产生结果|
|功能|不是因果|
|对应|不是因果|

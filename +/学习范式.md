# 回答的问题：模型是怎么获得知识的？
## 第一代：监督学习（Supervised Learning）

### 核心思想

```
输入(X)
+
标签(Y)
↓
学习映射关系
```

例如：

```
图片 → 猫
图片 → 狗
```

---

### 经典任务

- 图像分类
- 文本分类
- 房价预测

---

### 代表论文时代

```
1990~2018
```

大部分AI系统都是监督学习。

---

### 局限

需要大量标注：

```
100万张图片
↓
100万个人工标签
```

太贵。

---

## 第二代：无监督学习（Unsupervised Learning）

### 核心思想

```
只有X没有Y
```

自己发现规律。

---

### 代表方法

- KMeans
- PCA
- AutoEncoder

---

### 目标

```
聚类降维表示学习
```

---

## 第三代：半监督学习（Semi-Supervised）

### 核心思想

```
少量标签+大量无标签
```

例如：

```
1000张标注+100万张未标注
```

---

### 出现原因

现实世界标签很贵。

---

## 第四代：自监督学习（Self-Supervised）

这是你未来论文里最常见的。

---

### 核心思想

```
自己制造标签
```

例如：

BERT

```
今天[MASK]很好
```

预测：

```
天气
```

---

### 代表路线

#### Mask Learning

```
BERT
MAE
```

---

#### Contrastive Learning

```
SimCLR
MoCo
DINO
```

---

#### Predictive Learning

```
GPT
```

预测下一个Token。

---

### 当前地位

```
现代基础模型核心
```

---

## 第五代：强化学习（RL）

### 核心思想

```
试错
↓
奖励
↓
优化策略
```

---

### 代表

- AlphaGo
- RLHF
- RLAIF

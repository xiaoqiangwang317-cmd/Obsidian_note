回答的问题：

> 模型是怎么获得知识的？

## 第一代：监督学习（Supervised Learning）

### 核心思想

```
输入(X)
+
标签(Y)
↓
学习映射关系
```

例如：

```
图片 → 猫
图片 → 狗
```

---

### 经典任务

- 图像分类
- 文本分类
- 房价预测

---

### 代表论文时代

```
1990~2018
```

大部分AI系统都是监督学习。

### 代表方法：
* [[SVM]]
* [[决策树]]
* [[随机森林]]

---

### 局限

需要大量标注：

```
100万张图片
↓
100万个人工标签
```

太贵。

---

## 第二代：无监督学习（Unsupervised Learning）

### 核心思想

```
只有X没有Y
```

自己发现规律。

---

### 代表方法

- KMeans
- PCA
- AutoEncoder

---

### 目标

```
聚类降维表示学习
```

---
### 局限
```
学到的特征不够强
```

## 第三代：半监督学习（Semi-Supervised）

### 核心思想

```
少量标签+大量无标签
```

例如：

```
1000张标注+100万张未标注
```

---

### 出现原因

现实世界标签很贵。

---

## 第四代：自监督学习（Self-Supervised）

**这是你未来论文里最常见的。**
	一句话：
	从数据内部构造监督信号
---

### 核心思想

```
自己制造标签
```

例如：

BERT

```
今天[MASK]很好
```

预测：

```
天气
```

---

### 代表路线

#### Mask Learning 掩码学习
思想：

```
遮掉一部分让模型补回来
```

类似完形填空。

**代表方法:**
* [[BERT]]
* [[MAE]]
```
BERT  原句：我喜欢学习人工智能 变成：我喜欢学习[MASK] 预测：人工智能 训练目标：恢复被遮挡内容 BERT学到什么？不是答案。而是：语义表示 
MAE  图像版BERT 
```

---

#### Contrastive Learning  对比学习
## 核心思想

一句话：

```
相似靠近不同远离
```

```
SimCLR  
MoCo
DINO
```

---

#### Predictive Learning 预测学习

```
GPT
```

预测下一个Token。

---

### 当前地位

```
现代基础模型核心
```

---

## 第五代：强化学习（RL）

### 核心思想

```
试错
↓
奖励
↓
优化策略
```

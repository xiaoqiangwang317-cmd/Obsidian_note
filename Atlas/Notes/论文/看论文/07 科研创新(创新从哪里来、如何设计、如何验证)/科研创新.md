# 第一类：问题分析（Problem Analysis）

回答：

> **为什么现有方法不够好？**

任何论文第一件事：

不是提出方法。

而是：

证明：

```
现有方法存在问题
↓
必须改进
```

例如：

ResNet：

```
网络太深
↓
梯度消失
↓
性能下降
```

---

Transformer：

```
RNN
↓
无法并行
↓
长距离依赖差
```

---

SimCLR：

```
监督学习
↓
需要大量标签
```

---

你的课题：

```
主动测量
↓
噪声大标签少空间关联弱
```

这就是：

Problem。

三点。

# 第七类：创新评价（Innovation Evaluation）

回答：

> **怎样判断一个创新值不值得做？**

我建议以后自己做论文。

每个Idea。

都回答：

```
有没有解决实际问题？
有没有理论依据？
有没有实验支持？
别人有没有做？
创新是不是足够简单？
实验能不能验证？
```

这六个问题。

以后就是：

你的Idea过滤器。

# ⭐ 我想把这一层再提升一个层次（也是我认为整个知识库最有价值的一点）

前面的六层，本质上都是在回答**论文有什么（Paper Anatomy）**；而这一层，真正回答的是**论文是怎么诞生的（Paper Creation）**。

所以我建议把这一层固定成你以后每个研究想法都要经过的"科研流水线"：

```
① 发现问题（Problem）        │        ▼② 分析原因（Analysis）        │        ▼③ 寻找创新来源（Innovation Source）        │        ▼④ 设计方法（Method）        │        ▼⑤ 实验验证（Experiment）        │        ▼⑥ 提炼贡献（Contribution）
```

如果你以后每产生一个想法，都能按照这六步去推演，那么它就不仅仅是一个"灵感"，而是一个可以逐步发展成论文的方法。这也是导师和资深研究者思考课题时最常用的框架。

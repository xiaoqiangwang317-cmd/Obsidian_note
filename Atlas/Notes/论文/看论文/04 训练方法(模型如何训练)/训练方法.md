# 第一类：损失函数（Loss Function）

回答：

> **模型学得好不好，由谁评价？**

神经网络不会自己知道答案。

必须告诉它：

```
预测
↓
和真实值比较
↓
得到误差
↓
继续学习
```

这个误差：

就是：

```
Loss
```

---

## 分类任务

最经典：

```
Cross Entropy（交叉熵）
```

例如：

```
猫？
预测：0.95
真实：1
```

计算误差。

---

## 对比学习

代表：

```
InfoNCE
```

例如：

SimCLR

MoCo

BYOL（思想不同，但同属自监督路线）

---

## 回归任务

最经典：

```
MSE
MAE
```

例如：

```
房价预测
时间序列预测
```

---

## 常见Loss演化

```
MSE
↓
Cross Entropy
↓
Triplet Loss
↓
InfoNCE
↓
Contrastive Loss
```

---

# 第二类：优化器（Optimizer）

回答：

> **模型应该怎样更新参数？**

神经网络训练：

本质就是：

不断修改参数。

例如：

```
参数
↓
计算梯度
↓
更新参数
↓
继续训练
```

---

最经典：

## SGD

随机梯度下降。

深度学习起点。

---

后来发展：

```
SGD
↓
Momentum
↓
AdaGrad
↓
RMSProp
↓
Adam
↓
AdamW
↓
LARS
```

---

目前：

CNN：

大量使用：

```
SGD
```

Transformer：

大量使用：

```
AdamW
```

大Batch训练：

例如：

SimCLR

主要：

```
LARS
```

# 第三类：学习率策略（Learning Rate Scheduler）

回答：

> **学习速度如何调整？**

学习率：

太大：

```
学不会
```

太小：

```
学得太慢
```

所以：

需要动态调整。

---

最经典：

```
固定学习率
↓
StepLR
↓
MultiStepLR
↓
Cosine Annealing
↓
Warmup
```

---

现代Transformer：

几乎都会：

```
Warmup
+
Cosine
```

# 第五类：正则化策略（Regularization）

模型：


所以：

需要：

```
Regularization
```

---

代表：

```
Dropout
↓
Weight Decay
↓
Label Smoothing
↓
DropPath
↓
Early Stopping
```

---

作用：

```
提高泛化能力
```

# 论文阅读的终极框架（训练方法视角）

以后看任何论文，都先拆解：

---

### ResNet

```
损失函数：Cross Entropy
优化器：SGD
学习率策略：StepLR
数据增强：Random Crop、Flip
正则化：Weight Decay
```

---

### SimCLR

```
损失函数：InfoNCE
优化器：LARS
学习率策略：Cosine Annealing
数据增强：Random Crop、Color Jitter、Gaussian Blur
正则化：Weight Decay
```

---

### BERT

```
损失函数：Masked Language Modeling Loss
优化器：AdamW
学习率策略：Warmup + Linear Decay
数据增强：Mask Token
正则化：Dropout
```

---

### Informer

```
损失函数：MSE
优化器：Adam
学习率策略：Learning Rate Decay
数据增强：通常较少
正则化：Dropout
```

---

### 你的课题（网络测量）

```
损失函数：InfoNCE（对比学习）+ 下游任务损失
优化器：AdamW
学习率策略：Warmup + Cosine
数据增强：随机掩码、子图采样、时间扰动
正则化：Dropout、Weight Decay
```

# ⭐ AI论文阅读的四层分析框架（建议固定下来）

以后无论读哪篇论文，都按照下面四层去分析：

```
① 学习范式（为什么这样学习？）
监督学习？自监督学习？强化学习？        
│        
▼
② 模型架构（用什么模型？）
CNN？Transformer？GNN？        
│        
▼
③ 网络组件（模型由什么组成？）
Attention？GELU？RoPE？Projection Head？        
│        
▼
④ 训练方法（模型如何训练？）
Loss？Optimizer？Learning Rate？Data Augmentation？Regularization？
```

**这四层基本覆盖了绝大多数 AI 论文的 Method（方法）部分。** 后面我们还可以继续补充第五层——**实验设计（Datasets、Metrics、Ablation、Baseline）**，这样你的论文分析框架就完整了。

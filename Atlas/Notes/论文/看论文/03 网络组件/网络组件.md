# 第一类：基础计算层（Basic Layers）

负责：

> **数据如何计算、如何提取特征。**

---

## Linear（全连接层）

最基础计算单元。

```
输入
↓
线性变换
↓
输出
```

几乎所有神经网络都有。

---

## Conv（卷积层）

解决：

```
局部特征提取
```

例如：

```
边缘
↓
纹理
↓
目标
```

---

主要用于：

- [[CNN]]
- [[ResNet]]
- YOLO

---

## Embedding（嵌入层）

解决：

```
把离散数据
↓
变成向量
```

例如：

```
单词
↓
768维向量
```

或者：

```
Patch
↓
Embedding
```

---

主要用于：

- NLP
- [[Transformer]]
- [[ViT]]
- LLM

---

## Pooling（池化层）

作用：

```
降维
↓
保留主要特征
```

例如：

```
Max Pooling
Average Pooling
```

---

# 第二类：激活函数（Activation）

回答：

> **如何增加非线性表达能力？**

没有激活函数：

```
很多层Linear = 一层Linear
```

所以：

必须加入：

```
Activation
```

---

演化路线：

```
Step
↓
Sigmoid
↓
Tanh
↓
ReLU
↓
GELU
↓
SiLU
```

目前：

Transformer

主要：

```
GELU
```

现代LLM：

```
SiLU（SwiGLU）
```

---

# 论文阅读的终极框架（网络组件视角）

以后看任何模型，先拆解：

---

### ResNet

```
基础计算层：Conv
激活函数：ReLU
归一化：BatchNorm
网络连接：Residual
输出头：Classification Head
```

---

### Transformer

```
基础计算层：Embedding
注意力：Multi-Head Attention
前馈模块：FFN
归一化：LayerNorm
网络连接：Residual
位置表示：Positional Encoding
```

---

### ViT

```
基础计算层：Patch Embedding
注意力：Multi-Head Attention
激活函数：GELU
归一化：LayerNorm
前馈模块：MLP
网络连接：Residual
位置表示：Position Embedding
```

---

### LLaMA

```
基础计算层：Embedding
注意力：Grouped Query Attention（新版本）
激活函数：SiLU
前馈模块：SwiGLU
归一化：RMSNorm
位置表示：RoPE
网络连接：Residual
```

---

### SimCLR

```
Backbone：ResNet-50
基础计算层：Conv激活函数：ReLU归一化：BatchNorm网络连接：Residual输出头：Projection Head
```

## ⭐ 我建议再增加一个"黄金原则"

放在这一章最后，作为你以后读论文的核心思维。

```
读任何模型，都按下面七个问题拆解：① 用了什么基础计算层？   （Conv？Embedding？Linear？）② 用了什么激活函数？   （ReLU？GELU？SiLU？）③ 用了什么注意力？   （Self-Attention？FlashAttention？）④ 用了什么归一化？   （BN？LN？RMSNorm？）⑤ 用了什么连接方式？   （Residual？Dense？）⑥ 用了什么输出头？   （Projection Head？Classification Head？）⑦ 哪个组件是论文真正的创新点？
```

**这七个问题，就是以后分析 ResNet、ViT、SimCLR、BYOL、MAE、Informer，甚至你未来自己设计模型时最值得反复使用的一套分析框架。**

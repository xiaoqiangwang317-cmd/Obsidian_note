# 三、论文创新到底怎么想出来？

这个问题，我觉得比前面所有问题都重要。

而且很多导师不会讲。

事实上，**绝大多数论文的创新，不是凭空想出来的，而是沿着固定的几个方向改。**

我把近几年顶会论文（CVPR、ICCV、NeurIPS、ICLR、ICML）的创新归纳过，大概可以分成下面几类。

---

## 第一类：改网络组件（最多）

例如：

Transformer：

```
Attention
↓
FlashAttention
```

LLM：

```
FFN
↓
MoE
```

ResNet：

```
普通连接
↓
Residual
```

这是目前最多的创新。

---

## 第二类：改训练方法

例如：

Loss：

```
Cross Entropy
↓
InfoNCE
```

Optimizer：

```
SGD
↓
AdamW
```

Data Augmentation：

```
Random Crop
↓
Mixup
↓
CutMix
```

SimCLR：

其实：

创新有一半就在：

```
Data Augmentation
```

---

## 第三类：改模型架构

例如：

CNN：

↓

Transformer

Transformer：

↓

Mamba

这种创新最难。

---

## 第四类：多模块组合（工程创新）

例如：

```
RoPE
+
FlashAttention
+
MoE
+
RMSNorm
```

单独：

都不是你的。

组合：

就是创新。

工业界特别多。

---

## 第五类：提出新的任务

例如：

MAE。

以前：

没有：

```
Masked Image Modeling
```

后来：

提出了：

这个任务。

---

## 第六类：提出新的评价方式

例如：

新的Benchmark。

新的Dataset。

新的Metric。

这种论文：

也很多。

# 四、我觉得我们可以把"创新"也建立成一层

这是我最想和你讨论的。

因为你的目标已经不是学知识。

而是：

**写论文。**

所以：

我建议以后知识树最后增加一层：

```
07 科研创新（Research Innovation）
│├── 01 创新来源
│├── 02 创新模式
│├── 03 创新点设计
│├── 04 实验验证
│└── 05 写作表达
```

这里面，我们以后可以专门总结：

- 为什么 ResNet 能发顶会？
- 为什么 SimCLR 的创新成立？
- 为什么 MAE 会火？
- 为什么很多论文只是"换了一个模块"也能发论文？
- 如何判断一个想法有没有创新性？
- 如何把一个创新点包装成论文贡献（Contribution）？

# 总体研究思想

核心一句话：

> 针对网络延迟数据存在状态变化复杂、标注数据不足以及时序依赖关系难以充分建模的问题，本文首先利用自监督对比学习从大量无标签网络测量数据中学习鲁棒的网络状态表示，然后结合TimeMixer模型进行多尺度时间序列预测，实现精准的网络延迟预测。

# 创新点重新定义

## 创新点一（核心创新）

## 基于自监督对比学习的网络状态表征方法

解决的问题：

传统网络延迟预测：

输入：

```
RTT历史序列
```

直接预测。

问题：

- 网络状态复杂
    
- 噪声影响大
    
- 标签不足
    

导致：

模型学习到的是：

“表面延迟变化”

而不是：

“网络状态变化”。

---

你的方法：

利用：

### 时域增强

例如：

- jitter
    
- masking
    
- cropping
    

构造：

```
同一个网络状态

       ↓

两个不同扰动版本
```

然后：

InfoNCE：

让：

同状态：

[  
z_1 \approx z_2  
]

不同状态：

[  
z_1 \neq z_3  
]

得到：

更鲁棒的网络状态表示。

---

## 创新点二

## 基于TimeMixer的多尺度网络延迟预测方法

这里不要说TimeMixer是创新。

应该说：

> 构建基于TimeMixer的预测框架。

因为TimeMixer本身是已有模型。

你的贡献：

是：

把它应用到网络延迟场景，并融合对比学习表示。

原因：

网络延迟：

不是单尺度变化。

包含：

```
长期趋势
 ↓
链路负载变化

周期波动
 ↓
业务规律

短时扰动
 ↓
拥塞突发
```

TimeMixer：

利用：

- PDM
    
- FMM
    

进行多尺度信息混合。

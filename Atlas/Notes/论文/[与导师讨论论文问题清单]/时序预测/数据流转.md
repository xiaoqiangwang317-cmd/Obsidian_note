咱们顺着张量的 `Shape` 变化，走一遍最核心的数据流转。

**背景设定**：

- **数据集**：ETTm1（电力变压器数据，15 分钟采样一次）。变量特征维度 $C = 7$（比如油温、电流等）。
    
- **超参数**：我们假设 `batch_size = 16`，输入历史长度 `seq_len = 96`，预测未来长度 `pred_len = 336`。
    

#### 数据流转四步曲：

**Step 1: DataLoader 吐出数据**

- DataLoader 从 CSV 文件切片，产生一个 Batch 的历史数据送入模型。
    
- `batch_x` Shape: `(16, 96, 7)` -> `(Batch, Seq_Len, Features)`
    

**Step 2: 尺度分解（Multi-scale Decomposition）**

数据刚进模型，立马被 `AvgPool1d` 按照不同的降采样率（比如 window=2, 4...）切解成多个分辨率版本：

- Scale 0 (原图): `(16, 96, 7)` -> 保留最原始的高频细节。
    
- Scale 1 (降采样): `(16, 48, 7)` -> 数据长度减半，过滤掉部分高频。
    
- Scale 2 (粗尺度): `(16, 24, 7)` -> 数据再减半，只剩宏观走向。
    

**Step 3: 核心提纯与混合（PDM 模块）**

在每一个 Scale 内部（以 Scale 0 为例，Shape 仍是 `(16, 96, 7)`）：

1. **分解**：通过移动平均（或 DFT），一分为二：
    
    - 季节性分量 `Season`: `(16, 96, 7)`
        
    - 趋势性分量 `Trend`: `(16, 96, 7)`
        
2. **跨尺度交互（我们刚才看的代码）**：
    
    - Scale 1 的 Season `(16, 48, 7)` 被拉伸成 `(16, 96, 7)` 融合进 Scale 0。
        
3. **变量解耦嵌入（重点！）**：在这里，特征维度 $7$ 会被拆开/投影，进行独立的特征提取。
    

**Step 4: 多预测器输出（FMM 模块）**

处理完后，针对每一个 Scale，用一个线性层（MLP Predictor）直接把过去的长度映射到未来长度：

- Scale 0 Predictor: 输入 96 映射到 336 -> 输出 `(16, 336, 7)`
    
- Scale 1 Predictor: 输入 48 映射到 336 -> 输出 `(16, 336, 7)`
    
- Scale 2 Predictor: 输入 24 映射到 336 -> 输出 `(16, 336, 7)`
    

最后，把三个 Scale 的预测结果相加或做平均，输出最终的 `(16, 336, 7)`，打完收工。

# 一、先看一篇Reference的标准格式

例如：

```
[7] R. Girshick. Fast R-CNN. In ICCV, 2015.
```

拆开就是：

```
作者
↓
论文标题
↓
发表在哪里
↓
年份
```

即：

```
R. Girshick↓Fast R-CNN↓ICCV↓2015
```

---

再例如

```
[5] M. Everingham, ...The Pascal Visual Object Classes (VOC) Challenge.IJCV,2010.
```

就是

```
作者
↓论文名字
↓
IJCV（期刊）
↓
2010
```

---

## 所以Reference基本格式都是

```
Author(s).Title.Venue,Year.
```

其中

Venue（发表地点）

就是最重要的信息。

---

# 二、怎么看是会议还是期刊？

## 第一类：Conference（会议）

特点：

```
In CVPRIn ICCVIn NeurIPSIn ICMLIn ICLR
```

看到

> **In**

基本就是：

> **会议论文（Conference Paper）**

例如

```
Fast R-CNN.In ICCV.2015.
```

意思就是

发表于：

ICCV 2015。

---

再例如

```
In CVPR2014
```

就是

CVPR 2014。

---

### 常见顶会缩写（AI必背）

|缩写|全称|领域|
|---|---|---|
|CVPR|Computer Vision and Pattern Recognition|CV顶会|
|ICCV|International Conference on Computer Vision|CV顶会|
|ECCV|European Conference on Computer Vision|CV顶会|
|NeurIPS|Neural Information Processing Systems|AI顶会|
|ICML|International Conference on Machine Learning|ML顶会|
|ICLR|International Conference on Learning Representations|DL顶会|
|AAAI|AAAI Conference on Artificial Intelligence|AI顶会|
|IJCAI|International Joint Conference on AI|AI顶会|
|KDD|Knowledge Discovery and Data Mining|数据挖掘|
|ACL|Association for Computational Linguistics|NLP|
|EMNLP|Empirical Methods in NLP|NLP|
|SIGIR|Information Retrieval|检索|

以后看到：

```
In XXX
```

大概率就是会议。

# 三、怎么看期刊（Journal）

例如：

```
IEEE Transactions on Neural Networks1994
```

没有

```
In
```

而是

```
IEEE Transactions on...
```

这就是期刊。

---

再例如

```
IJCV
```

全称：

> International Journal of Computer Vision

Journal

就是期刊。

---

### 常见AI顶刊

|缩写|全称|
|---|---|
|TPAMI|IEEE Transactions on Pattern Analysis and Machine Intelligence|
|IJCV|International Journal of Computer Vision|
|JMLR|Journal of Machine Learning Research|
|TNNLS|IEEE Transactions on Neural Networks and Learning Systems|
|TCSVT|IEEE Transactions on Circuits and Systems for Video Technology|

---

例如

```
IJCV2010
```

就是：

发表于：

International Journal of Computer Vision。

# 四、怎么看Book（书）

例如

```
Bishop.Neural Networks for Pattern Recognition.Oxford University Press.1995.
```

注意：

出现：

```
Oxford University Press
```

出版社。

这就是：

**书（Book）**

不是论文。

---

例如

```
A Multigrid Tutorial.SIAM.2000.
```

SIAM

也是出版社。

所以：

这是一本书。

# 五、怎么看arXiv？

例如

```
Maxout Networks.arXiv:1302.43892013.
```

这就是：

预印本。

---

## 什么叫预印本？

论文流程：

```
作者写论文
↓
上传arXiv
↓
投稿CVPR
↓
审稿
↓
录用
↓
正式出版
```

很多作者会先放：

```
arXiv
```

所以：

arXiv不是会议。

不是期刊。

它只是：

**公开论文服务器。**

---

为什么有的只有arXiv？

有几种可能：

---

### 第一种

刚上传。

还没投稿。

---

### 第二种

投稿失败。

没有正式发表。

---

### 第三种

作者就是想公开。

例如：

Meta

OpenAI

Google

很多论文都会：

```
先发arXiv
```

然后几个月后：

```
ICLR
```

# 六、为什么有的Reference写得很长？

例如：

```
IEEE Transactions on Neural Networks,5(2):157–166,1994.
```

这里：

```
5
```

表示：

Volume（卷）

```
2
```

表示：

Issue（期）

```
157-166
```

表示：

页码。

所以：

```
5(2):157–166
```

意思就是：

```
第5卷第2期157-166页
```

# 九、以后精读论文，我建议你新增一个步骤——"Reference分析"

不要只看正文，还要看参考文献。我建议建立一个简单的统计表：

|作者|标题|类型|是否顶会/顶刊|为什么引用|
|---|---|---|---|---|
|He et al.|SPPNet|ECCV|✅|作者前作，提供基础网络设计|
|Girshick|Fast R-CNN|ICCV|✅|下游目标检测应用|
|Glorot|Xavier Initialization|AISTATS|✅|初始化方法|
|Bengio|Learning long-term dependencies|IEEE TNN|✅|梯度消失理论来源|

这样做有两个好处：

1. **快速认识领域里的核心人物和经典论文**（例如He Kaiming、Yoshua Bengio、Ross Girshick）。
2. **理解作者为什么引用这些工作**，从而把握论文背后的技术演进路线，而不仅仅是看懂当前这一篇。
